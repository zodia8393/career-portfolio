# 조형준 · 데이터 프로젝트 포트폴리오

[프로젝트별 상세 자료 열기](https://zodia8393.github.io/career-portfolio/)

실무의 분석 과정·판단·결과와 개인 프로젝트의 실행 기록을 정리한 정적 사이트입니다.
이력서와 제출용 포트폴리오는 이 저장소에 포함하지 않습니다.

## 처음 보는 분께

1. **분석 결과와 업무 활용:** [강원 방문통행 분석](https://zodia8393.github.io/career-portfolio/gangwon/#impact)에서 실제 데이터 규모·비교 기준·결과 활용을 확인할 수 있습니다.
2. **코드 구성과 검증:** [교통카드 전처리](https://zodia8393.github.io/career-portfolio/migration/#code-design)는 입력 설정과 공통 계산의 분리, [CCTV 평가](https://zodia8393.github.io/career-portfolio/cctv/#code-design)는 공개 JSON 검산 예시를 설명합니다.
3. **실제 공개 소스와 테스트:** [MobilityFlow README](https://github.com/zodia8393/mobility-flow-platform#코드-읽는-순서)에서 입력 처리 → DB 적재 → 품질 검사 순으로 코드를 읽을 수 있습니다.

이 저장소는 **설명·시각자료를 제공하는 정적 포트폴리오**입니다. 회사 프로젝트의 전체 원본 코드를 공개한 저장소가 아닙니다. 설명용 코드와 실제 공개 소스를 구분해 표시합니다.

## 공개 범위

프로젝트명은 이력서·제출 포트폴리오와 통일했습니다. 각 페이지에서 방법과 선택 이유, 작업 타임라인, 시행착오, 최종 결과와 의미를 읽을 수 있습니다. 본문은 A4 폭의 세로 문서이며 보고서 PDF도 A4 세로형입니다. 인쇄 시 접힌 세부 근거·용어가 펼쳐지고 동작 데모는 웹에서 확인합니다. 확인되지 않은 작업일은 날짜 대신 단계 순서로 표기합니다.

- 회사 원천 행·전체 계산 코드는 공개하지 않습니다. 공개 승인된 결과 지도·집계 도식·설명·선별 평가 수치를 포함합니다. 결과 지도는 원본 이미지와 동일하며 확대 화면·범례·해석을 함께 제공합니다. 춘천의 개인 식별자·개별 이동 궤적은 게시하지 않습니다.
- CCTV의 별도 학습 실행과 분류 평가를 하나의 모델 개선 성과로 연결하지 않습니다.
- MobilityFlow는 2026.08.31의 보존 기록을 조회합니다. 현재 수집 상태를 표시하지 않습니다.
- ETF 화면은 사건 요약을 단계별로 읽는 데모입니다. 계좌·금액·실제 API 호출 기능이 없습니다.
- 서울 도로소통 화면의 데이터 출처: 서울특별시·서울 열린데이터광장.

## 저장소 구조

```text
index.html              프로젝트 목록과 핵심 근거 바로가기
<프로젝트명>/index.html  업무 활용·코드 구성·타임라인·검증 조건
assets/                 공통 스타일·동작 데모·공개 집계 JSON·도식
reports/                기존 A4 세로 상세 보고서
```

웹 상단의 업무 활용·코드 구성 설명은 제출 후 보강한 내용입니다. 기존 보고서와 제출 PDF는 유지했습니다. PDF 번호·쪽수는 공통 제출본 기준이며 회사별 제출본의 순서와 다를 수 있습니다.

## 결과 시각자료

- 강원 방문통행: 2026.09.09 보정본의 춘천 4개 단지 전후 이동 지도·275/20건 집계, 09.08 춘천 내부 출발·도착 분포, 09.02 설·추석 날짜별 비교. 기존 R1–R4 접근 경로도 별도 보존하며 분석 대상·단위 차이를 표시합니다. 기존 PDF는 8월 기록이며 최신 후속 작업은 웹에서 확인합니다.
- 데이터플랫폼: 삼락IC→대저JC 접근 지도, 구간 위치와 속도 차이, 원본 배경지도 표기 유지.
- 관광교통: 강릉역 후보 격자 지도, 강릉역 분석영역 라벨, 수요 색상과 후보 테두리 구분.
- CCTV·교통카드·MobilityFlow: 평가 오류·49개 산출물·복구 시험 수치를 막대 길이로 표현.
- ETF 운영: 비식별 기록을 바탕으로 한 상태 복구 순서도. 실거래 화면이 아님.

모든 상세 페이지는 세로 문서이며 지도 원본은 새 탭으로 확대할 수 있습니다. 자동 생성한 가상 지도를 실제 분석 결과처럼 사용하지 않습니다.

## 로컬 열람

Python 3으로 이 디렉터리에서 다음 명령을 실행한 뒤 `http://localhost:8000`에 접속합니다.

```bash
python3 -m http.server 8000
```

MobilityFlow의 데이터 수집 자체를 재현하려면
[별도 저장소의 실행 안내](https://github.com/zodia8393/mobility-flow-platform#실행)를 확인하세요.
이 사이트의 실행 기록 데모에는 API 키가 필요하지 않습니다.

## 배포

GitHub Pages의 `main` 브랜치 `/` 경로로 게시합니다. `.nojekyll`을 사용하며 별도 빌드·서버·의존성이 필요하지 않습니다.
각 보고서 PDF와 QR 링크는 동일 프로젝트의 고정 경로로 연결됩니다.

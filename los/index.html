화성시 버스 혼잡도·LOS 검증

노선 식별과 재차인원 누락을 구분하고, 혼잡도·서비스수준 수식이 일관되게 계산되도록 보완했습니다.

문제에서 결과까지

문제

동일한 노선명이 다른 노선 코드를 가리키고, 미확보 자료가 0명으로 계산되면 혼잡도 해석이 달라집니다. 수식 오류와 자료 공백을 별도로 다뤄야 했습니다.

선택

노선명만으로 결합하지 않고 노선 ID·유형을 대조했습니다. 공란을 보호하는 수식을 적용하고 기존 값·수식·서식의 보존 여부를 나누어 확인했습니다.

결과·활용

4개 마을버스 노선을 추가해 227개 노선 분석표를 만들었습니다. 미확보 1건은 공란과 비고로 남겨 실제 0명과 구분했습니다.

구현 과정과 선택 이유

  1. 기존 계산 검토

    수식의 참조와 호환성을 점검하고 공란이 혼잡도·LOS 값으로 잘못 변환되지 않도록 했습니다.

  2. 노선 단위 대조

    4개 노선의 유형과 코드를 확인해 기존 시내노선과 중복·혼동을 방지했습니다.

  3. 누락의 의미 보존

    33-4의 9월 13일 자료는 재조회에도 확보되지 않아 공란·비고 처리했습니다. 미운행으로 단정하지 않았습니다.

  4. 수식과 표현 함께 검증

    추가 행까지 수식과 조건부서식을 확장하고, 공통 검증에서 계산 가능한 값·공란·기존 비수식값·경계값을 각각 확인했습니다.

검증 근거

  • 노선 대조 JSON에서 시내·마을 H102를 별도 코드로 확인했습니다. 기존 시내 63개는 유지하고 마을노선은 160개에서 164개로 늘었습니다.
  • 신규 4노선 × 4일의 16개 조합 중 15건을 확보했습니다. 미확보 1건을 값 0으로 채우지 않았습니다.
  • 2026.10.12 공통 검증 기록: 유효 계산 828개, 공란 64개, 기존 비수식값 3,276개와 경계값 11개를 확인했습니다. 서로 다른 검증 범주이며 노선 수와 합산하지 않습니다.

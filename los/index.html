초록

화성시의 혼잡노선 증차 검토용 Excel을 대상으로 첨두시 최대 재차인원, 좌석 수, 혼잡도와 LOS 수식을 점검했다. 현재 보존된 최종본은 2026년 9월 11–14일의 시내 63개·마을 160개, 총 223개 노선이다. 노선·일 892개 중 값이 있는 828개와 공란 64개를 구분하고 기존 비수식값 3,276개 및 수식 경계값을 검증했다. 별도 신규 4노선 조회에서는 16개 노선·일 중 15개 자료를 확보했으나, 이를 현재 최종본의 노선 수에 합산하지 않았다.

01연구 문제와 범위

원문 대조 · 발표자료·보고서·현재 산출물의 해당 부분 확인

연구·개발 목적

기존 「혼잡노선 증차 — 최대 재차인원을 활용한 LOS 분석」의 계산과 입력 정합성을 보완해 노선별 혼잡 수준 검토에 사용할 분석표를 유지한다. 증차 대안의 효과를 측정한 연구가 아니라 기존 지표의 자료·수식 검증 업무다. [1] [2]

이 사례에서 다루는 문제

혼잡노선 증차 검토에 사용하는 첨두시 최대 재차인원·좌석 수 기반 혼잡도와 LOS를, 노선별 자료 공백과 식별 오류 없이 계산할 수 있는가?

문서에 기재된 목적과 수행 내용을 바탕으로 질문을 요약했습니다. 원문의 직접 인용은 아닙니다.

구분내용과 근거
기준 산출물화성시 LOS 20260911–0914 수식수정 Excel의 시내버스·마을버스 시트. 현재 확인된 노선은 63+160=223개. [1]
기간·관측 단위2026.09.11–14, 노선별·일별 첨두시 최대 재차인원. 223×4=892개 노선·일. [1] [2]

실제 수행공란 보호, 수식·참조 및 조건부서식 검토, 노선명과 코드 대조. 유효 828개·공란 64개와 기존 비수식값 3,276개를 별도 검사. [2]

완료 범위현재 최종본에는 신규 4노선 추가 행이 없다. 227개 노선 완성본으로 표현하지 않으며, 증차 후 서비스 개선 효과도 측정하지 않았다. [1] [3]

이전 페이지의 ‘227개 노선’은 신규 노선 추가 이력과 현재 최종본을 혼합한 표현이어서, 이번 원문 대조에서 정정했다.

  1. 01노선명·유형·코드 대조

노선명만으로 결합하지 않고 노선 ID·유형을 대조했습니다. 공란을 보호하는 수식을 적용하고 기존 값·수식·서식의 보존 여부를 나누어 확인했습니다.

  1. 기존 계산 검토

    수식의 참조와 호환성을 점검하고 공란이 혼잡도·LOS 값으로 잘못 변환되지 않도록 했습니다.

  2. 노선 단위 대조

    4개 노선의 유형과 코드를 확인해 기존 시내노선과 중복·혼동을 방지했습니다.

  3. 누락의 의미 보존

    33-4의 9월 13일 자료는 재조회에도 확보되지 않아 공란·비고 처리했습니다. 미운행으로 단정하지 않았습니다.

  4. 최종본과 추가 조회를 분리 검증

    최종본의 유효 828개·공란 64개 노선·일, 기존 비수식값 3,276개와 경계값 11개를 대조했습니다. 신규 4노선은 조회 결과와 추가용 코드를 확인하되 현재 최종 Excel 반영으로 표현하지 않습니다.

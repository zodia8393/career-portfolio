## 공개 집계 검산

저장소 루트에서 Python 3 표준 라이브러리만으로 실행합니다.

```bash
python3 work/reproduce.py
```

검사 범위: OD 1,728행의 중복·일수 환산, 18개 시군 × 2기간 × 2방향 × 2상대지역의 144개 요약값. 원천 카드번호·개별 통행 자료는 포함하지 않습니다.

`assets/work-evidence/gangwon-od.csv`의 한 행은 평일/주말 × 출발 지역 × 도착 지역입니다. 같은 시군 내부 이동도 CSV에 들어 있지만 유입·유출 요약에서는 제외합니다. 평일은 5일, 주말은 2일입니다. `period_trips`는 기간 합계, `daily_trips`는 일평균입니다.

교통카드 결과 JSON은 내부 보존 파일을 대조한 집계 기록입니다. 공개 검산은 JSON의 산술·상태 확인까지만 수행합니다. 원천 파일을 공개하지 않으므로 이 저장소만으로 14개 CSV의 실제 셀 일치를 재검증할 수는 없습니다. 49개 전체 검증은 2026년 7월 업무 기록, 14개 재대조는 2026년 9월 추가 점검입니다.

측정하지 않은 처리시간·업무시간 개선율은 없습니다. R/Python 속도 비교와 실제 업무 A/B를 실행 완료로 표시하지 않습니다.

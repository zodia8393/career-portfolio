재전송 전에 기존 요청의 결과를 확인

2026년 7월 20일 외부 API의 취소여부 필드가 빈 문자열로 반환되면서 기존 요청을 검토 필요 상태로 남기는 문제가 발생했습니다. 신규 요청을 다시 보내거나 기록을 수동으로 삭제하지 않고 기존 식별자를 조회해 실제 결과를 확인했습니다.

문자열 필드의 존재와 타입 검사는 유지하면서, 실제 응답 규칙에 맞게 빈 문자열 처리를 보완했습니다. 확정 결과의 단일 반영과 감사 기록의 중복 여부를 확인하고 같은 유형의 응답을 회귀 테스트에 추가했습니다.

배포는 S3 버전별 산출물과 설치 파일의 해시를 대조하고, 이전 코드와 실행 설정을 보존하는 방식으로 관리했습니다. 별도의 같은 날 배포 기록에는 전체 테스트 481개 통과가 남아 있습니다. 이 수치를 장애 한 건의 테스트 개수로 표현하지 않습니다.

01 / 진행 과정

입력 차이를 정리하고 계산 결과 대조

지역별 파일 경로와 예외 조건을 실행 설정으로 분리해 계산 코드를 복제하지 않고 사용할 수 있도록 했습니다. 알려진 컬럼 명칭을 변환하고 숫자 자료형을 맞췄으며, 입력이 모호할 때 임의의 파일을 선택하지 않도록 처리했습니다.

원주 검증에서는 중간 R 마스터의 중복과 재생성 식별키를 비교 기준에 맞춘 뒤 업무 컬럼을 대조했습니다. 최종 산출물은 동일함을 확인했지만, 모든 중간 파일의 원시 행이 처음부터 같았다는 의미는 아닙니다.

일부 체인 자료 처리는 정해진 컬럼 순서를 전제로 합니다. 따라서 임의 형식의 파일을 자동으로 이해하는 기능으로 표현하지 않으며, 새 지역은 컬럼 순서와 예외 조건, 표본 결과를 확인한 뒤 적용해야 합니다.

지역·폴더 지정파일·컬럼 확인공통 계산기존 결과 대조지역별 저장

공개 예시는 입력 선택·명칭 변환의 구조 설명입니다. 회사 원천이나 전체 계산 코드를 웹에서 실행하지 않습니다.

실행 전 확인 예시

필수 파일이 없으면 누락된 역할을 표시하고 중단합니다. 선택 지역과 파일의 지역이 다르면 불일치를 표시하며, 같은 역할의 파일 후보가 여러 개라 모호하면 사용자가 정리한 뒤 다시 실행하도록 합니다.
